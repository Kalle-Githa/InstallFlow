
Kör detta i din PC i appsettings.json filen:
"ConnectionStrings": {
    "DefaultConnection": "Server=ULTRAG\\SQLEXPRESS;Database=InstallFlowDb;Integrated Security=SSPI;TrustServerCertificate=True"
  },
  
Kör detta i din Mac:  
"ConnectionStrings": {
  "DefaultConnection": "Server=localhost,1433;Database=InstallFlowDb;User Id=sa;Password=YourStrong@Passw0rd;TrustServerCertificate=True;"
}

Måste köra detta på macen SQL i den ordningen:
DELETE FROM CartItems;
DELETE FROM Carts;
DELETE FROM ProductCategories;
DELETE FROM Products;
DELETE FROM JobLaborRows;
DELETE FROM JobMaterialRows;
DELETE FROM Jobs;
DELETE FROM Assignments;
DELETE FROM Customers;

och sedan:
dotnet ef database update
